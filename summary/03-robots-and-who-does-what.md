# 03 · Robots and who does what

## The cloud robot (runs even when your PC is off)
| Routine | When (your time) | Job |
|---|---|---|
| Daily Ops | every day 07:00 | health check · fixes new Junia drafts · adds internal links · report + email |
| Weekly Review | Monday 08:00 | + 4 article briefs · price check · Quora ideas · refreshes these summaries |
| Monthly Report | 1st, 09:00 | Google/Bing data · speed · scoreboard · decisions for you |

You get each report as an **email**, a **Google Doc** (title ends OK / Needs you / ALERT) and **PM Tracker** updates.

## The browser helper (your PC, Tue + Fri 10:00)
Uses your Chrome to make up to 2 Junia drafts per run and to ask Google to index new pages. It only runs while the PC, the Claude app and Chrome are open. Keep Chrome visible.

## Safety limits
- Max 6 links and 3 draft fixes a day. **0 publishes.**
- DataForSEO at most $5 a month.
- Every change is backed up, checked, and undone if the check fails.
- Two failed checks in 7 days pause the robot automatically.

## 🛑 Emergency stop
GitHub repo → **Add file → Create new file** → name `AUTOPILOT_PAUSED` → **Commit changes**. Delete that file to restart.

## Who does what
| Robots and agents | Only you (~20–30 min a week) |
|---|---|
| research, briefs, Junia drafts | **Publish** (Save Draft → read → Publish) |
| QA and fixes on drafts | run `--replace-live` / `--apply` commands |
| internal links, indexing requests | Quora "Post" (or "post 1, 3") |
| affiliate forms (your standing OK) | passwords, captchas, payment and tax |
| affiliate replies, link placement | "send" for any email in your name |
| reports and emails to you | edits to the routines' text if blocked |

The agent may change LiteSpeed and Rank Math settings only with you present: one at a time, after your OK, logged with the undo.
