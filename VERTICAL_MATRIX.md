## 🧩 SCHEMA TYPES

| Page Type | Schema (JSON-LD via Rank Math) | Notes |
|---|---|---|
| BoFu pillar ("best X") | `Article` + `ItemList` (ranked tools) + `BreadcrumbList` | `ItemList` order must match on-page ranking |
| Single-tool review | `SoftwareApplication` + `Review` (author = Person) | Third-party reviews are eligible for review snippets; never self-review |
| MoFu "X vs Y" | `Article` + `BreadcrumbList` | Comparison tables in HTML; no fake aggregate ratings |
| ToFu how-to | `Article` + `BreadcrumbList` | Google deprecated `HowTo` rich results (2023); keep steps in HTML |
| FAQ sections (any page) | `FAQPage` (optional) | Google limits FAQ rich results to authoritative gov/health sites, so it carries AI/semantic value only |
